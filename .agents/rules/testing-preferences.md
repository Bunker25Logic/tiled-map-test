# Diretrizes de Desenvolvimento e Testes

- **Não abrir o navegador nem executar o `browser_subagent`** automaticamente ao fazer alterações. O usuário prefere testar manualmente no próprio navegador dele.
- Validação técnica deve ser realizada exclusivamente via terminal (`npm run lint`, `npm run build`, checagens TypeScript).
- Sempre responder em Português do Brasil.
